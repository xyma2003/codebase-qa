先复用现有源码扫描上限，保持聊天模型、嵌入、默认检索及评测数据不变。安全策略独立于语言模型执行，不靠关键词检测来保证模型不会受骗。遇到新失败保留原始错误，按证据修正，不改变模型参数重跑。

本轮针对本地单人产品。公网服务的身份鉴别、租户隔离、集中密钥管理和操作系统执行沙箱不在当前交付内；需要上线多人使用时单独设计与验收。

验收记录只说明对应测试范围，不承诺不存在漏洞。真实模型验收需要原版成功基线、密钥及明确的攻击样本和预算，不能用模拟输出来报告防御成功率。
