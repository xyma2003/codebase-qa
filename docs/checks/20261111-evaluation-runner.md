# 本地评测运行器验收

日期：2026-11-11。结果：本地模拟运行、输入输出归档和独立回读通过；真实模型评测与人工评分未进行。

## 运行行为

运行器使用固定开发集的原始问题与模式，每题独立会话，同题顺序追问。真实产品 Agent、工具、引用校验、规划结构和会话存储参与执行，模型为本地 `FunctionModel`。本地模型只按实际工具结果进行演示，不接收参考标注，也不预置每题正确答案。

每轮保存准确输入、模型实际收到的原生消息/指令/工具定义、SDK 消息、工具调用与结果、原始和核对后输出、耗时及可获得用量。失败保留原异常、消息和堆栈；同题后续轮次阻塞，其他未开始的题不执行，运行器不重试失败轮次。

快照和会话库位于独立运行目录。仅源码模式禁用问答缓存、向量搜索和索引文件列表；会话集合字段标明为占位，向量状态为 `not_built`，没有更新正式索引。模型 API 请求被禁止，真实 provider 用量和费用均为未知。
