日期：2026-11-11。结果：评审包、导入、评分和报告回读通过。本次使用合成评分记录，没有实际人工语义评审或真实模型质量结论。

## 功能行为

评审包从已有封存运行生成，提供完整多轮问题、原回答、引用、检查点和固定规则。导入核对运行编号、归档 SHA256、数据集指纹、规则字节摘要和逐轮输出 SHA256；评审工作包与评分报告独立保存，不回写原始运行。

已完成输出可以保持待评审或填入人工声明的四维分数、评审者及具体理由。支持只提交部分轮次，未提交项保留原状态和分母。重复或未知轮次、错输出、改规则/参考上下文、缺少评审信息，以及把失败或未运行项改成回答完成，都会拒绝。

整体与分类报告沿用固定 40/30/20/10 权重和逐轮通过条件。只要存在未运行或待评审项，最终均分/通过率保持为空；已知失败项仍生成完整上下文、回答、版本化源码链接及评语材料。程序计算声明的评分，不代替语义判断，也不自动猜测根因。
