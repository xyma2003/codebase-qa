# 源码查找验收

日期：2026-11-10。结果：本功能的本地验收通过，没有调用真实聊天模型。

## 本次行为

新增 `find_code`，供 Agent 和 MCP 共用。它直接查选定 Commit 的快照，支持文本、路径和 Python 函数或类名；文本模式可定位原向量分块没有覆盖的模块配置、导入语句。查找预览不作为源码引用，需用 `read_file` 获取原文及本次引用编号。

| 模式 | 行为 |
| --- | --- |
| `text` | 逐行匹配字面子串，每个命中行返回一条；覆盖现有支持扩展名的文件。 |
| `path` | 在快照清单中匹配路径子串，不读取文件正文。 |
| `symbol` | 用 AST 定位 Python 类、函数、异步函数及嵌套定义，返回限定名称及首尾行。不解析其他语言的定义。 |

默认忽略大小写，支持路径子串过滤。结果按路径、行号排序，以 `offset` 和 `next_offset` 分页。单文件最多 1 MiB、单次最多读取 10 MiB、检查 2000 个候选文件。资源上限和跳过原因单独返回；有跳过或扫描受限时，没有命中不能证明整个仓库没有对应内容。
