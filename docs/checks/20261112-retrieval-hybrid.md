# 符号、路径与向量融合的离线检索对照

日期：2026-11-12。

## 对照条件

复用上次成功回读的固定版本 `af7dcd1` 原索引，共 533 个分块，不重建索引、不重新嵌入。固定问题、源码、模型和 Top 5 不变，仅比较原向量检索与固定的字面查找 / RRF 融合。没有调用聊天模型。

融合从问题中最多提取 8 个带下划线、驼峰或 `.py` 的代码名称，按路径、Python 定义或字面文本查找。两路结果使用 `1/(60+rank)`，同一路重复位置只计一次；并列结果按路径与行号排序。纯自然语言未识别到名称时只有向量一路。没有查询改写、重排模型或根据参考答案调参。

## 结果

融合只改善了少量候选定位，没有改善完整覆盖，不能据此宣称回答质量提升。默认方式继续为 `semantic`；`hybrid` 作为显式实验选项供 Python、MCP 和真实评测入口使用。真实评测仍要求原版成功基线与密钥。

所有 180 条返回位置和原文均核对固定 Git 对象，逐轮组覆盖率独立重算一致。公开[结果 JSON](20261112-retrieval-hybrid.json)保存全部候选位置、原文摘要和实现摘要。该集是公开单仓库开发集，单轮原问题的一次 Top 5 不能代表完整 Agent 多步研究或跨仓库能力。
