# 首次模型调用前超时的归档修正 · 2026-11-23

文档提交 `3bcbce9` 的 [CI](https://github.com/xyma2003/codebase-qa/actions/runs/45148606491) 中 Linux 全通过，Mac 418 项中的本地超时测试报错。原作业 137603986899，原始调用链为 runner.run_local → archive.verify_archive：

```text
ValueError: An attempted local turn has no model request record
```

测试设置每轮 0.01 秒，模拟模型响应等待 0.1 秒。在较慢的 SDK 启动或调度下，截止时间可以先于第一次模型回调到来。这是合法的“一轮执行已尝试、模型调用为 0、结果失败”，旧校验却假定每个尝试的本地轮次都有模型调用。

现在仅对本地、TimeoutError、真实记录为 0 次的失败，明确写入 `before_first_model_request=true`。校验同时检查失败状态、错误种类、调用记录及计数；完成状态或实际存在调用时不允许此标记，没有明确标记的缺失记录仍拒绝。输出依然失败，后续轮次仍阻断、不重试、不生成答案，也不增加虚构调用、Token 或费用。

没有更改 0.01 秒测试期限、默认业务超时、模型或运行参数。原超时测试允许实际发生的 0 或 1 次调用，计数须与档案完全一致；另增确定性“SDK 尚未开始”的测试和伪造标记拒绝测试。原 `ALLOW_MODEL_REQUESTS` 在取消后仍恢复，旧归档及真实后端规则保持兼容。
