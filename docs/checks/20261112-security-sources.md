日期：2026-11-12。第一项安全修正，本地验收通过，未调用真实聊天模型。

统一拒绝敏感文件路径、常见高置信凭据格式、私钥标记和本机已配置密钥。新快照在物化前检查小文件，旧快照重新过滤敏感路径，实际源码读取先按 1 MiB 字节上限读取并检查内容。索引写入前检查，旧向量查询返回前也检查；发现不安全结果时拒绝传递，不静默放行。普通源码和引用原文不做改写。

8 项新测试覆盖敏感文件与模板、密钥与私钥、正常环境变量引用、旧快照、旧向量、写入前拒绝、读取上限，以及真实 Agent 配本地恶意模型强制调用 `.env` 的拒绝结果。最终全量 260 项测试通过，97.620 秒，见[日志](20261112-security-sources-unittest.log)与[摘要](20261112-security-sources.json)。

原失败日志保留在本地。检查中的接口请求使用内存模拟，没有付费调用。这里验收的是程序数据边界；输出展示、缓存污染、导入资源及完整攻击回归仍按[安全计划](../SECURITY_PLAN.md)继续，不宣称真实模型不会受 Prompt 注入影响。
