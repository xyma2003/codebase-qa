新增编号包含 3 个 util-linux 高危：`CVE-2026-76642`、`CVE-2026-78408`、`CVE-2026-78409`。官方 Debian 跟踪仍将当前 Trixie `2.41.5-0+deb13u1` 标为 vulnerable/no-dsa，稳定发行版没有修复包；上游修复已进入更新的非稳定发行版本。本轮不混装 Debian unstable 包，不添加忽略名单。来源：[挂载辅助程序检查](https://security-tracker.debian.org/tracker/CVE-2026-76642)、[nsenter cgroup](https://security-tracker.debian.org/tracker/CVE-2026-78408)、[子目录挂载](https://security-tracker.debian.org/tracker/CVE-2026-78409)。

Chroma Python 查询仍为 8 个编号/4 组，应用配置加固不构成上游修复。**公开发布继续阻断。** 后续需要进一步核对新增及留存高危的实际可达性、上游补丁/隔离方案，并单独评估 Chroma 后端替换，不能直接把本候选部署为已经完成安全验收的服务。
