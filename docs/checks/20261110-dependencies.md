## 本次行为

Agent 与 MCP 新增共用工具 `get_file_dependencies`：`outgoing` 查看文件内的导入引用，`incoming` 定位可能指向该文件的引用。目标文件始终使用仓库相对路径，`source_root` 默认仓库根目录；`src` 布局必须明确指定，不使用当前解释器环境猜测路径。

按选定快照的 `.py` 文件和 `__init__.py` 建立候选名称映射，保留源码位置、原文、别名及条件/函数上下文。每个导入名称或识别出的动态调用计一条引用；一行可以产生多条记录。结果按源文件与代码位置分页，不递归展开循环关系。

`from 包 import 名称` 可能先取得属性，也可能尝试导入子模块；运行时还存在导入缓存与钩子。因此本工具保留文件候选及成员未追踪标记，不仅凭同名文件确认成员最终来源。[Python from 导入规则](https://docs.python.org/3.12/reference/simple_stmts.html#import)、[Python 导入系统](https://docs.python.org/3.12/reference/import.html)

| 返回信息 | 含义 |
| --- | --- |
| `targets` | 指定源目录中匹配到的模块文件，或可能的子模块文件；不是运行成功证明。 |
| `resolution` | 保留未定位、多个候选、通配符、动态导入及越过源目录的相对导入等状态。 |
| `member_not_followed` | 不追踪 `from` 导入成员的属性绑定或重导出链。 |
| `context` | 导入位于函数、条件、循环或异常分支等位置，不据此判断分支是否执行。 |
| `unresolved_count` | 当前检查范围内未完整定位的引用数量，包含前页和分页探测项；并非目标文件缺失依赖数或全仓总数。 |
| `evidence_unavailable` | 原文超过 1000 字符时不自动提供完整引用，保留位置供按行读取。 |

只定位源码文件路径，不模拟父包初始化副作用、导入钩子、成员执行及完整影响范围。动态调用识别覆盖显式 `__import__`、导入别名对应的 `importlib.import_module` / `import_module` 名称；不宣称识别所有间接动态加载。未定位不等于确认属于外部依赖。
